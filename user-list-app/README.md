# Project Setup and Execution Instructions

## 🔧 System Requirements
- **Node.js**: v22.9.0  
- **npm**: v10.8.3  

---

## 📦 Step 1: Install Dependencies

To install all necessary Node.js packages, run the following command:

```bash
npm install
```

---

## 🚀 Step 2: Start the Application

To start the Node.js server:

```bash
npm start
```
